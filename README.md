# Redmi AX3000 ImmortalWrt 25.12 filtered APK repository

This orphan branch contains the signed APK repositories produced by the
standard ImmortalWrt build for the Redmi AX3000:

- source branch: redmi_ax3000-25.12-filtered-port
- source commit: 8f73bbf1dbaa79da4a7c55def6e52ffda708968c
- firmware version: r0+37891-8f73bbf1db
- target: qualcommax/ipq50xx
- package architecture: aarch64_cortex-a53
- kernel: 6.12.92

The repository contains only the 175 packages generated by the filtered
Redmi AX3000 configuration. It is not a complete ImmortalWrt package mirror
and does not include unselected USB, SCSI, filesystem, or unrelated device
packages.

## Repository layout

- targets/qualcommax/ipq50xx/packages: target and kernel packages
- packages/aarch64_cortex-a53/base: base packages
- packages/aarch64_cortex-a53/luci: LuCI packages
- packages/aarch64_cortex-a53/packages: community packages
- keys/public-key.pem: local ECDSA repository public key
- distfeeds.list: ready-to-use APK repository list

## Configure APK

The matching firmware already contains keys/public-key.pem as
/etc/apk/keys/public-key.pem. To use these package indexes, replace the
distribution feed list and refresh APK:

~~~sh
wget -O /etc/apk/repositories.d/distfeeds.list \
  https://raw.githubusercontent.com/qwqgong-ui/Redmi_AX3000_immortalwrt/packages-25.12-filtered-port/distfeeds.list
apk update
~~~

All four repository indexes were verified with the included public key.
A local client test found all 175 packages and resolved base-files,
kmod-ath11k-ahb, luci, and cgi-io from the expected indexes.

Do not use this repository with the 24.10 firmware. The matching firmware
release is v25.12-filtered-port-r37891-8f73bbf1db.
